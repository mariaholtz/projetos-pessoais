# 🎲 Lançador de Dados

## 📖 Sobre

Este projeto consiste em um simulador simples de lançamento de dados desenvolvido em Python.
O usuário pode lançar dois dados de seis faces quantas vezes desejar, enquanto o programa registra a quantidade de lançamentos realizados.

O projeto foi desenvolvido com o objetivo de praticar estruturas de repetição, criação de funções, geração de números aleatórios e manipulação de listas.

---

## 🚀 Tecnologias

- Python 3

---

## 📚 Bibliotecas utilizadas

- **random** — utilizada para gerar valores aleatórios correspondentes aos resultados dos dados.

---

## 🧠 Conceitos praticados

- Funções
- Estruturas de repetição (`while`)
- Entrada e saída de dados (`input` e `print`)
- Manipulação de listas
- Geração de números aleatórios
- Variáveis de controle e contadores
- Uso de parâmetros em funções

---

## 🎮 Como funciona

1. O usuário informa se deseja lançar os dados.
2. O programa gera aleatoriamente dois valores entre 1 e 6, representando dois dados.
3. Os resultados dos dados são exibidos na tela.
4. O usuário pode continuar lançando os dados ou encerrar o jogo.
5. Ao finalizar, o programa informa quantas vezes os dados foram lançados.

---

## 🎲 Exemplo de funcionamento

```text
Deseja lançar os dados? (sim/nao) sim

[4, 2]

Deseja lançar os dados? (sim/nao) sim

[6, 5]

Deseja lançar os dados? (sim/nao) nao

Você lançou os dados 2 vezes!
```
