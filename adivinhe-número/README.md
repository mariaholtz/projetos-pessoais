# 🎯 Adivinhe o Número (Versão com Funções)

## 📖 Sobre

Este projeto consiste em um jogo de adivinhação desenvolvido em Python, no qual o computador gera um número aleatório entre 1 e 100 e o jogador deve descobri-lo em até 10 tentativas.

Esta versão foi criada como uma evolução da versão inicial do projeto, utilizando funções para organizar melhor o código e torná-lo mais modular.

---

## 🚀 Tecnologias

- Python 3

---

## 🧠 Conceitos praticados

- Funções
- Modularização de código
- Estruturas condicionais (`if`, `elif`, `else`)
- Laços de repetição (`while`)
- Tratamento de exceções (`try` / `except`)
- Geração de números aleatórios (`random`)
- Entrada e saída de dados
- Controle do fluxo da aplicação

---

## 🎮 Como funciona

- O computador escolhe um número aleatório entre 1 e 100.
- O jogador possui até **10 tentativas** para acertar.
- Após cada palpite, o programa informa se o número secreto é maior ou menor.
- Ao final da partida, o jogador pode iniciar uma nova rodada sem precisar reiniciar o programa.
