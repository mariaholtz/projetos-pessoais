# 🎯 Adivinhe o Número

## 📖 Sobre

Este projeto consiste em um jogo de adivinhação desenvolvido em Python, no qual o computador gera um número aleatório dentro de um intervalo definido pelo usuário. 
O objetivo é descobrir o número secreto em até 10 tentativas.

Esta foi a primeira versão do projeto e serviu como base para uma versão posterior, na qual o código foi reorganizado utilizando funções para melhorar sua estrutura e reutilização.

---

## 🎮 Como funciona

1. O usuário informa o intervalo de números para a partida.
2. O computador escolhe aleatoriamente um número dentro desse intervalo.
3. O jogador tenta adivinhar o número.
4. Após cada tentativa, o programa informa se o palpite foi maior ou menor que o número secreto.
5. O jogo termina quando o jogador acerta ou quando o limite de 10 tentativas é atingido.
